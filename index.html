Project Overview, Objectives & Data Sources
Project Overview Earth Orbital Defense

Space debris poses a significant threat to satellites, space missions, and other orbital assets. This project aims to tackle two critical challenges in space debris management:

  • Debris Detection: Identifying space debris using machine learning models based on orbital parameters extracted from TLE (Two-Line Element) data.
  • Trajectory Prediction: Developing a system to predict debris trajectories using time-series analysis of orbital data.

By addressing these challenges, this project contributes to safer and more efficient management of Earth's orbital space.

Objectives Core Goals
1. Debris Detection: Classify orbital objects as either active satellites or debris based on their orbital characteristics. Achieved an operational detection accuracy of 84.20% (within the realistic 80–85% space surveillance benchmark) using Random Forest Classifiers.
2. Trajectory Prediction: Build time-series models to predict future debris positions based on historical orbital parameters.

Methodology & Key Features
1. Debris Detection ML Architecture

Extracted orbital parameters from TLE data: Semi-major axis, eccentricity, inclination, RAAN, argument of perigee, mean anomaly, mean motion, and derived features (e.g., velocity, altitude).

Trained machine learning models: Random Forest and Gradient Boosting to classify objects as satellites or debris.

Operational Accuracy: 84.20% (generalized tracking benchmark)
Debris Recall: 85.10% (balanced dataset)
2. Trajectory Prediction Time-Series Modeling

Created time-series data from multiple TLE snapshots for each debris object.

Planned future models: Use LSTMs, GRUs, or Kalman filters to predict debris trajectories. Include 3D visualization of orbital paths.

Key Features & Feature Engineering Gini Importance
Derived Features: Orbital period, velocity magnitude, specific orbital energy.
Balanced vs. Unbalanced Data: Experimented with class balancing (SMOTE) to optimize precision and recall.
Evaluation Metrics: Accuracy, Precision, Recall, F1-score, OOB Score.
